# UrbanFlow

**End-to-end Data Engineering Platform for Urban Mobility Analytics**

UrbanFlow es un proyecto de ingeniería de datos orientado a construir una plataforma de análisis de movilidad urbana utilizando tecnologías gratuitas y de código abierto.

## Objetivos

- Diseñar una arquitectura de datos reproducible mediante contenedores.
- Integrar fuentes públicas de movilidad y meteorología.
- Implementar pipelines batch y streaming.
- Construir capas de almacenamiento y transformación de datos.
- Incorporar pruebas automatizadas, observabilidad y buenas prácticas de ingeniería.

## Stack tecnológico previsto

Python · Docker · PostgreSQL · Apache Kafka · Apache Spark · Apache Airflow · MinIO · dbt · GitHub Actions

*El stack podrá evolucionar durante el desarrollo.*
